# Repositorio del Máster en Desarrollo Full Stack

¡Bienvenidos a mi repositorio del Máster en Desarrollo Full Stack! Este espacio contiene todo el material relacionado con las actividades, materia, y módulos del programa.

## Estructura del Repositorio

### 1. **Actividades**
En la carpeta `activities/` se encuentran las actividades prácticas realizadas durante el máster. Estas están organizadas por número de actividad y contienen:
- Documentos de enunciado.
- Archivos de trabajo y soluciones.
- Capturas de pantalla de commits y otros recursos relevantes.

### 2. **Materia**
En `materia/` se encuentran los módulos completos en formato PDF, que abarcan desde HTML y CSS hasta despliegue y testing. Este apartado contiene principalmente teoría utilizada como referencia durante el máster.

### 3. **Módulos**
La carpeta `modules/` contiene subcarpetas organizadas por temas específicos del máster, como:
- `01-FrontEnd-HTML-CSS/`
- `02-Git-terminal/`
- `03-JavaScript-VanillaJS/`
- `04-Angular/`
- `05-MongoDB/`
- `06-NodeJS/`

En este apartado se encuentran los ejercicios y ejemplos prácticos realizados con el material de las clases.

## Cómo Navegar el Repositorio
- Cada carpeta está claramente etiquetada para facilitar la navegación.
- Los archivos están organizados por actividad o módulo para un acceso rápido.

## Contribuciones
